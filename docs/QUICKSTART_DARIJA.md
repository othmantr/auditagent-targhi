# AuditAgent Targhi: البداية

هاد الحزمة كتخدم مع Claude Code وCodex CLI، حتى إلا كنت كتفتحهم داخل Antigravity.

## التثبيت

حل Terminal فمجلد الحزمة، خاص Python 3.11 أو أكثر:

```bash
python3 installer.py --host both --scope user --dry-run
python3 installer.py --host both --scope user
```

فـWindows تقدر تحتاج `py -3` بلاصة `python3`.

## الاستعمال

فـClaude Code من بعد التثبيت المباشر:

```text
/auditagent-targhi audit
```

فـCodex:

```text
$auditagent-targhi audit this project
```

إلا استعملتي Claude plugin عبر marketplace، الأمر كيكون:

```text
/auditagent-targhi:auditagent-targhi audit
```

ما تثبّتش Claude skill وClaude plugin بجوج إلا كنت قاصد التكرار.

## شنو غادي يدير؟

كيكتاشف المشروع، كيراجع المكوّنات المناسبة باستعمال الأدوات المتاحة، وكيخرج تقرير بالأدلة وخطة مقسّمة. ما كيبدّلش كود التطبيق حتى تصادق. تقدر توافق على مرحلة أو على مجموعة مراحل، وهو يتبعهم بالتتابع مع التحقق ويرجع ليك ملي يكمل أو يلقى عائق.

مثال موافقة:

> موافق على phase-1 وphase-2 من الخطة اللي عرضتي. نفّذهم بالتتابع وتحقق من كل مرحلة. رجع ليا إلا تبدّل النطاق أو وصلتي لعملية حساسة ما وافقتش عليها، وعطيني التقرير ملي تسالي هاد المجموعة.

## الذاكرة والحدود

كل مشروع عندو `.auditagent/` فيها الحالة والتقارير والخطة. خليها خاصة وما تطلعهاش لـGitHub. الذاكرة كتقلّل إعادة القراءة، ولكن قراءتها حتى هي كتستهلك tokens.

البرنامج ماشي sandbox: كيتحقق من الموافقات والمراحل داخل أوامرو، ولكن ما يقدرش يمنع أداة عندها صلاحية كتابة من التعديل خارجه. ونتائج المراجعة كتعتمد على جودة الفحص والأدلة. ما كيخدمش فالخلفية من بعد ما تسد الجلسة.

README فيه تفاصيل GitHub والتثبيت والإزالة. الحزمة واجدة باش ترفع المصدر، ولكن ما ترفعاتش تلقائياً لحساب GitHub وما تثبّتاتش فحاسوبك.
